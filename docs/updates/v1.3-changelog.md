| Änderung | Stand |
| --- | --- |
| Implementierung | OFFEN / IM CODE / AUSGELIEFERT |
| Automatisierte Prüfung | PASS / FAIL / NOT RUN |
| Manuelle Prüfung | PASS / FAIL / BLOCKIERT / NOT RUN |
