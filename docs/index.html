04 / HOW IT WORKS

So werden Tests bestätigt

01

Real prüfen

Funktion am tatsächlich laufenden Gerät, in OBS oder Twitch testen. Nichts ungeprüft abhaken.

02

Ergebnis melden

Beim Test „Funktioniert“, „Fehler“ oder „Blockiert“ wählen und den vorbereiteten Befehl als GitHub-Kommentar einfügen.

03

Belege ergänzen

Build-ID, kurze Erklärung und bei Bedarf einen bereinigten Screenshot direkt im selben GitHub-Kommentar ergänzen.

04

Geschichte behalten

Neue Versionen hängen neue Tests an. Offene Punkte, frühere Häkchen und Kommentare bleiben bestehen.
